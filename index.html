First-time Setup

Your habit data will live in a private GitHub Gist — synced across all your devices. This setup runs once per browser (token is stored in the URL hash, so it's cache-proof).

1
Go to github.com/settings/tokens/new → Note: habits → Expiration: No expiration → Scope: check gist only → click Generate token → copy it.
2
Go to gist.github.com → Description: habits-data → Filename: habits.json → Content: {} → click Create secret gist → copy the Gist ID from the URL (the long string after your username).
3
Paste both below. The URL will update — bookmark that URL. On any new device, just open that bookmark and you're synced instantly.
