New Profile

Connect a private GitHub Gist as your personal data store. Takes ~8 min once.

1
Go to github.com/settings/tokens/new → Note: habits → Expiration: No expiration → check only ☑ gist → Generate & copy token.
2
Go to gist.github.com → Description: habits-data → Filename: habits.json → Content: {} → Create secret gist → copy the ID from the URL (long string after your username).
3
Fill in below and click Save. The URL will update with your config encoded in the hash (#abc123…). Bookmark that URL immediately — it works on any device, any browser, after any cache clear. Share it with no one.
